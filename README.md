# 🤖 AI Assistant (Python)

A simple desktop-based AI Assistant built using **Python** and **Tkinter**. The application provides a graphical user interface (GUI) where users can interact with the assistant through text commands. It can perform basic tasks such as opening websites, displaying the current date and time, performing calculations, telling jokes, and more.

---

## ✨ Features

- 💬 Interactive chat interface
- 👋 Greeting responses
- 🕒 Display current time
- 📅 Display current date
- 🌐 Open Google
- ▶️ Open YouTube
- 💬 Open WhatsApp Web
- 🔍 Search anything on Google
- 🧮 Simple calculator
- 😂 Random jokes
- 💡 Motivational quotes
- 🧹 Clear chat window
- 🚪 Exit application

## 💻 Available Commands

| Command | Action |
|---------|--------|
| hello / hi / hey | Greeting |
| how are you | AI responds |
| what is your name | Shows assistant name |
| time | Displays current time |
| date | Displays today's date |
| google | Opens Google |
| youtube | Opens YouTube |
| whatsapp | Opens WhatsApp Web |
| search <query> | Searches Google |
| calculate <expression> | Calculates mathematical expressions |
| joke | Displays a random joke |
| motivate | Shows a motivational quote |
| clear | Clears the chat window |
| exit / quit / bye | Closes the application |
